about=QGIS Lite Agent & MCP Bridge is a clean-room engineered, lightweight assistant and MCP server for QGIS 3.x and 4.x (Qt5 and Qt6). It compresses project context to under 150 tokens using SHA-256 delta snapshots, enforces strict per-layer privacy opt-in, validates all AI-proposed PyQGIS actions through a static AST security sandbox with Human-in-the-Loop approval, audits EPSG:5253 (TUREF / TM30) CRS compliance, and exports multi-step workflows directly to native QGIS .model3 files or standalone Python scripts. Supports Antigravity, Claude Code, Cursor, Codex, OpenCode, Gemini, DeepSeek, Grok, and Ollama.
